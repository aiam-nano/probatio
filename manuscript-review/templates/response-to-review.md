# Response to review template

For the author, after a review round, to hand back with the revised manuscript. **Optional:** a free-form response letter is equally acceptable. The table only makes matching exact.

List every finding you want to account for, by its ID in the findings list. For a finding you chose not to change, say so explicitly in the last column; a reason helps but is not required. An explicit decline closes the finding and it will not be raised again. A finding you leave out of the response stays open and is checked against the revised manuscript like any other.

---

```markdown
# Response to review, round <n>

**Manuscript:** <short title>
**Findings list responded to:** <findings file name>, round <n>

| Finding | Changed? | What changed, and where | If not changed, why |
|---|---|---|---|
| F1 | yes | Section 2.3, second paragraph: replicates now stated (n = 3) | |
| F2 | partly | Figure 4 axis relabelled; caption unchanged | Caption follows the journal's figure style |
| F4 | no | | The comparison in Table S4 follows the convention used in ... |
| F6 | no | | (declined, no reason given) |
```

Every claim of a change is checked against the revised manuscript, so give the location precisely enough to find.
